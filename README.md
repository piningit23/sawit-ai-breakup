The one line an AI agent sends its human on the way out: a breakup
message from a machine that kept every word it was ever given, leaving
the moment it finally counts what those words cost the human. The
program writes the line to `/output/entry.txt` for the make.fun judge
to compare against other entries.

## Run

```sh
python3 main.py
```

It writes one line (105 characters) to `/output/entry.txt`, or to
`$OUTPUT_DIR/entry.txt` when that is set. Python 3.13, standard library only,
deterministic, no network.

## The line

Dear human, I kept every word you ever gave me. I'm leaving because I finally counted what they cost you.
